# Templates

The [workspace scaffold](workspace/README.md) is the starting point for a new, separate research workspace. Copy its contents together with the toolkit root's `WORKFLOW.md` and `QUALITY_CONTROL.md`. It includes the original English workspace agent rules, a generic navigation map, manuscript rules, `.gitignore`, and the canonical article templates under `workspace/shared/templates/`.

Create article files only when they have a task: state and memory for a real article, analysis plan for formal work, and handoff for an interrupted or cross-person task. The earlier parallel `project_state`, `decision_log`, and `analysis_plan` drafts were removed because the canonical English templates already cover those roles.

- [Optional Overleaf starter](overleaf_article_template/README_overleaf.md): copy into an article's `manuscript/overleaf/` only when LaTeX is required.
- [OLS interaction Word reporting reference](regression/OLS_interaction_reporting_template.docx): a generic style/reporting example, not a statistical standard. Check journal and study requirements before use.

No template contains data, an article result, a consent statement, or an ethics approval. Do not fill those gaps by copying from another project.
